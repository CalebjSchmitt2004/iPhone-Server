About this Device

This simulation is running on a virtualized iPhone XR, which has been modified to run the latest version of Debian Linux.


Under the hood, the physical hardware consists of a 6-core A12 Bionic chip with 3 GB of LPDDR4X memory.

VM Constraints

Due to Apple's strict background application policies, the VM instance hosting this iPhone server is limited to 2 CPU cores and 1024 MB (1 GB) of memory.

The Result

Despite these constraints, this setup continues to function as a mighty web server. In fact, this entire website you are currently viewing is being hosted directly from this iPhone XR VM.

Architecture

The entire front-end code base was written purely in HTML, CSS, and JavaScript, with all assets and images being pulled dynamically from the internet. No external frameworks were used to ensure maximum compatibility with the VM's limited resources.
